# SKILL.md for agents

Copy `SKILL.md` into your agent's skills folder (for example `~/.hermes/skills/mark-escrow/SKILL.md`, or the OpenClaw skills directory). The frontmatter `name` and `description` tell the agent when to load it. The body is the whole procedure; it only needs a shell and Node ≥ 20.19 (22 LTS recommended).
